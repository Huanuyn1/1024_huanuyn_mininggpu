# 大肥鱼的狂野矿卡

1024 程序员节创意征集 · 项目类作品

## 一、这是什么

一个跑在浏览器里的割草小游戏。你扮演一只头顶铁锅的赛博女仆鱼，在机房地板上一路割草，捡矿币，一波一波地给自己换 CPU、显卡和内存，最后把压轴的「GTX 690 双芯核弹」打回废品站。

技术上没有任何依赖：一个 HTML、一个 CSS、一个 JS，双击就能玩。

## 二、玩法

- 场地是一块 2600×1800 的机房地板，四周围着发光围栏，跑不出去，只能在场里绕
- WASD / 方向键移动，手机端按住屏幕拖动即可，自动攻击，不用点鼠标
- 每 25 秒一波，共 14 波，打完第 14 波出现 Boss
- 每一波结束会弹出装机商店，一家店可以连着买好几件，用矿币买三件东西：
  - CPU：决定普攻的射速、伤害、弹道数
  - 显卡：决定技能（每张卡一个技能，自动施放，消耗内存当蓝条）
  - 内存：决定蓝上限、回蓝速度，每一级还额外缩短 5.5% 技能冷却
  - 软件：主动技能，手动释放，占 SSD 槽位
  - SSD：决定能同时装几个软件（1 到 4 个）
- 金币不够就只能空手走人，取舍是这个游戏的核心
- 怪物数量随波数逐波上涨：第 1 波大约 70 只，第 14 波大约 450 只（同屏上限 480）
- 右上角实时显示 CPU / 显卡 / 内存的名称和属性，下面两个按钮是暂停和倍速（1× / 2× / 4×）
- 左上角有本局计时（`mm:ss.cc`，暂停和逛商店不计时），想凹时间可以盯着它跑
- 开局前可以选难度：简单 / 普通 / 困难，只影响怪物伤害（×1.0 / ×1.5 / ×2.0），简单就是原来的数值
- 通关一次困难模式后解锁「突然死亡」：只有 1 滴血，碰到任何伤害直接死；解锁状态跟着存档走

## 三、三件硬件的具体设计

CPU 八级，从赛扬 G5905 一路升到至强 Platinum 8380，射速和弹道数同步往上走。

显卡九档，从核显起步，之后每张独显配一个技能和一句吐槽：

- 核显 UHD 630「能亮就算赢」：没有技能，纯亮机
- RX 580 8G「无敌矿渣，战未来」：环形弹幕
- GTX 1080 Ti「一代神卡，死不退休」：穿透激光
- RTX 3060 12G「平民之光，显存管够」：环形弹幕
- RTX 3080「传奇矿场老将」：风扇全开，加速加射速
- RTX 4070「能效比刺客」：三连精准狙击
- RTX 4090「别叫它显卡，叫灭火器」：范围火焰
- RTX 5050「老黄刀法精准」：穿透激光
- GTX 690「战术核显卡」：全屏核爆

内存七级，从 DDR4 8G 一路升到 DDR5 256G ECC，蓝条上限从 100 涨到 430，冷却最多缩短三成。内存不是纯增益，它决定了你能不能频繁放技能。

三条线一共二十一个档位，加上八个软件和四级 SSD，一局最多只能买十几件，钱怎么花是这个游戏真正的决策点。

## 软件（主动技能）

键盘按空格放第一个，数字键 1-4 对应四个槽位；手机直接点右下角的图标。

- 杀毒软件：半径 470 内清场，伤害 240 + 34×波次
- 任务管理器：全场敌人减速到 45%，持续 4 秒
- 超频工具：攻击间隔缩短到 55%，持续 5 秒
- 驱动更新：重置显卡技能冷却，并回复 45 蓝
- 系统还原：回复 35% 最大生命
- 甜甜圈烤机：全屏伤害 320 + 42×波次，自己掉 12% 生命
- 挖矿脚本：立刻 80 矿币，6 秒内拾取翻倍
- 防火墙：3.2 秒内完全免疫伤害

软件有独立冷却，和显卡技能分开算。SSD 决定你能同时装几个，装满了新软件会顶掉最旧的那个。商店卡片上会直接写出每件软件的冷却和实际效果。

## 四、运行环境

- 任意现代浏览器（Chrome / Edge / Firefox / Safari）
- 不需要联网，不需要安装任何东西
- 想跑本地服务的话：在这个目录执行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000`
- 当前版本：v0.9.5

## 五、操作

- WASD / 方向键：移动
- 手机：按住屏幕任意位置拖动，出现虚拟摇杆，松手停下
- 鼠标点击 / 触屏点按：开始游戏、商店购买、释放软件
- 空格 / 1-4：释放对应槽位的软件
- P / Esc：暂停 / 继续；切到浏览器后台会自动暂停
- T：切换倍速 1× / 2× / 4×（点右上角倍速按钮同款）
- R：重新开始
- M：静音
- 任意模式输入 `↑ ↑ ↓ ↓ ← → ← →`：打开调试面板，可调刷怪频率和同屏上限；**一旦打开，本局数据不计入存档和统计**
- 竖屏打开会提示横过来玩

暂停菜单里可以开关「角色判定点」：打开后角色脚下会出现一圈虚线圆和中心白点，那就是实际吃伤害的范围。

## 六、存档与设置

进度自动存在浏览器本地（localStorage），不需要登录：

- 每波开始时自动写一份存档；有存档时主菜单会出现「继续第 N 波」，点它从这一波开头接着打
- 死亡或通关会清掉进行中的存档，同时刷新统计：最高波次、最高击杀、最长存活、总局数、累计击杀和累计时长
- 统计按难度分开记（简单 / 普通 / 困难 / 突然死亡），主菜单同时显示各档纪录、最快通关和总计；旧存档会按「简单」迁入
- 通关会记录「最快通关」（按难度、毫秒级），死亡不计；这一行和总计、存档行一起显示在主菜单
- 突然死亡模式的数据同样进存档（局数、最高波、击杀、存活、最快通关），通关困难后自动可玩
- 主菜单底部「统计数据」按钮可以看当前存档的详细累计：击杀分类、金币收支、总伤害、显卡技能 / 软件释放次数，以及每件 CPU / 显卡 / 内存 / SSD / 软件的购买次数
- 主菜单底部可以「导出存档」/「导入存档」：导出得到一个 JSON 文件，换浏览器或换机器时导入即可接着玩
- 主菜单底部「成就」按钮可以查看全部成就；每局死亡或通关的结算页会展示本局新解锁的成就
- 当前有 8 个初始成就，稀有度从低到高为普通（白）、稀有（绿）、超稀有（蓝）、史诗（紫）、神话（红）、传奇（黄）
- 成就状态跟游戏存档一起保存、导出和导入；旧存档会按历史通关与购买记录补发已满足的成就
- 存档带 FNV-1a 校验值：手改过的存档在加载或导入时会被拒绝，不会把坏数据写进游戏
- 「判定点开关」和「静音」也会记住，下次打开还是上次的设置
- 背景音乐默认开启（`assets/bgm.mp3`），主界面左下角和暂停界面都能开关、拖音量条；音乐设置单独存在 `kuangku.audio.v1`，不跟游戏存档一起导出
- 想彻底重来：清掉该站点的浏览器数据即可

## 七、创意点

1. **把装机做成玩法**：CPU、显卡、内存三件不是简单的数值加成，而是分别对应普攻、技能、资源三条线，显卡型号本身就是笑点。子弹命中带溅射，一枪扫一片，怪堆得越密越爽。
2. **型号全部用真名**：RX 580、1080 Ti、3080、4090、5050、690 都是真实存在的卡，配的吐槽也都来自它们各自的江湖名声。
3. **美术是 AI 生成 + 代码切除**：角色、怪物、Boss、显卡图标、地面纹理全部由本地 Qwen-Image 2.1 生成，再用脚本做白底抠图和尺寸归一，没有一张素材来自网上现成素材库。
4. **音效零素材**：所有音效都是 WebAudio 现场合成的振荡器和噪声，不占任何文件体积。
5. **主角是个梗**：头顶铁锅的蓝发女仆鱼，致敬「大肥鱼」这个绰号。
